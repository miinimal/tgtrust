# Paid API operator desk (demo)

The second-origin demo for tgtrust Trust Desk (`desk/`). A data API that sells reports to AI agents; its assistant
checks the incoming agent's `tgtrust-req/v1` signature in the browser, asks Trust Desk (a partner network on another
origin, after the visitor agrees on a card) which tier fits, and serves the request only after the operator confirms.
Nothing is charged and no real API is called.

| Path | What it is |
| --- | --- |
| `paid_api_desk.hocon` | the network: one front agent, `api_gatekeeper`, with Trust Desk as a partner tool |
| `paid_api_desk.network.json`, `agent-mcp.json`, `.well-known/`, `bridge/` | generated by the reference build |
| `agent-manifest.json` | manifest; `allowed_peers` is Trust Desk's origin; actions `inspect_caller` (read) and `serve_request` (irreversible) |
| `app.js`, `site-actions.js`, `demo-page.js`, `index.html`, `demo.css` | the page and its actions |
| `site.js` | the skill's assistant mount, with the "Serve this request?" dialog |
| `runtime/`, `vendor/` | the same runtime and verifier bytes as `desk/` (a test checks it) |

The partner URL is `https://miinimal.github.io/tgtrust/trust_desk`. Private context: the front agent lets only
`request_id` pass to the partner. The checks of spec section 6 run against this site and Trust Desk on two local
origins: `tests/test_desk_e2e.py`.

Build and check from the repository root:

```bash
node desk/tools/agentify/scripts/build_network.mjs demo-api/paid_api_desk.hocon --manifest demo-api/agent-manifest.json --runtime demo-api/runtime --check
```
