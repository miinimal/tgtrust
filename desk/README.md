# tgtrust Trust Desk

An open agentic website (Worldwide Agentic Web MVP spec, profile 0.2). Another site's agent asks it before it gives
an unknown AI agent a task or a payment. The conformance map and the contest notes are in `docs/COGNIZANT.md`.

Network URL (once hosted): the folder that holds `agent-manifest.json`, then `trust_desk`.

## Files

| Path | What it is |
| --- | --- |
| `trust_desk.hocon` | source of truth for the agent network: `trust_desk` (front agent), `evidence_checker`, `limit_advisor` |
| `trust_desk.network.json` | the resolved network the browser loads; generated, never edited by hand |
| `agent-manifest.json` | the site manifest: network, default router (hosted Otari), closed peer policy, site actions |
| `links.json` | the publisher's peer-network bindings (none) |
| `agent-mcp.json`, `.well-known/`, `bridge/` | generated by the build from the manifest |
| `index.html`, `desk.css`, `desk-page.js`, `favicon.svg` | the page: the desk form, samples, live-lookup consent, result, assistant |
| `site.js` | mounts the assistant (the skill's template; Trust Desk has no irreversible action) |
| `samples/` | the demo agent's Concordium card (copy of `examples/concordium/agent-card-mainnet.json`) and a forged credential |
| `verifier.js` | the browser verifier: cards, credentials, request signatures, tiers, Concordium reads; mirrors the Python code |
| `lib/blindrsa.js` | the holder page's blind-RSA module, byte for byte (`tgtrust/webapp/blindrsa.js`) |
| `desk.js`, `app.js` | the page object: evidence on the desk, live-lookup choice, check and recommend |
| `site-actions.js` | registers `get_desk`, `check_agent`, `recommend_limit` (all read-only) |
| `issuers.js` | the issuer keys the desk trusts, pinned with the date read |
| `runtime/` | the browser runtime, copied unchanged from `cognizant-ai-labs/agentic-web` `skills/agentify-website/runtime` (Apache-2.0, `runtime/LICENSE.txt`); `tools/agentify/RUNTIME.sha256` pins every file |
| `tools/agentify/` | the reference build, server and partner-check scripts from the same repository (Apache-2.0, `LICENSE`) |
| `tests/` | Node tests, also run by `tests/test_desk.py` in the Python suite |

## Build and check

From the repository root:

```bash
node desk/tools/agentify/scripts/build_network.mjs desk/trust_desk.hocon --manifest desk/agent-manifest.json --check
node --test "desk/tests/*.test.mjs"
```

Change the `.hocon` or the manifest, never the generated files, then run the build without `--check`.
